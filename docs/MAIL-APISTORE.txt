Buen día. Estoy interesado en la API de apistore, cuya documentación está
publicada en https://apistore.pcnt.io, para validación de identidad en un
sistema privado de venta y control de tarjetas en Argentina.

La documentación indica que la API vive en https://apistore.pcnt.io, pero al
probarla encuentro que:
  - cualquier GET devuelve el HTML de la documentación (130 KB), incluso para
    /v1/information/persons/30756789 y /v1/login/jwt;
  - POST /v1/login/jwt devuelve 405 de nginx;
  - api.pcnt.io, api.apistore.pcnt.io, app.pcnt.io, gateway.pcnt.io y
    services.pcnt.io no resuelven por DNS;
  - pcnt.io responde desde un parking de Cloudways (403) y
    apistore.pcnt.io:8080 no conecta;
  - apistore-dev.pcnt.io devuelve la misma documentación estática.
Parece un sitio de documentación y no el gateway de la API.

Les pido por favor:

  1. La URL base real de la API (host y path) y el esquema de autenticación
     definitivo: ¿POST /v1/login/jwt con username/password? ¿El header es
     "Authorization: JWT <token>" o "Authorization: Bearer <token>"?
     La documentación muestra JWT en la sección general y Bearer en el ejemplo
     de barcode; necesito confirmar cuál acepta el gateway.

  2. Un trial o credenciales de prueba para validar:
     - GET /v1/information/person-renaper/{dni}/gender/{M|F}
       (nacimiento, domicilio, ejemplar, emisión, vencimiento, fallecimiento,
       id_tramite_principal)
     - GET /v1/information/person/{cuit} (AFIP: birth_date, domicilio)
     - POST /v1/information/barcode (procedure_number de 11 dígitos)
     - GET /v1/information/persons/{dni} (lista de CUITs)

  3. Precio por consulta y por volumen (por ejemplo 1.000, 10.000 y 100.000
     consultas/mes), moneda, impuestos y si hay descuento por prepago.

  4. Mínimo mensual o compromiso mínimo.

  5. Límite de requests por segundo y por día. ¿Hay rate limit por cuenta,
     por IP o por endpoint?

  6. Si existe un endpoint por lote (batch) y su formato/límite. Nos interesa
     resolver nacimiento y domicilio en bloque usando los CUITs del padrón.

  7. Forma de pago y facturación (factura A/B, CUIT, plazo, orden de compra).

  8. Pregunta técnica sobre el trámite:
     Para el DNI 30756789 tenemos el trámite real 00744230016 (11 dígitos).
     ¿El campo id_tramite_principal de
     /v1/information/person-renaper/30756789/gender/M devuelve 744230016

     ¿Pueden confirmar el valor exacto que devuelve hoy su API para ese DNI?

     necesitamos la foto del documento.
